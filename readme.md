# Корпоративный портал Ритма

Статический сайт для GitHub Pages. Исходники: ветка `main`. Публикация: ветка `gh-pages`, корень репозитория. При выпуске обе ветки указывают на одну проверенную версию сайта.

Страницы написаны на HTML, стили и значок находятся в `assets/`, скачиваемые документы — в `files/`. Сборка и внешние зависимости не требуются. Используются относительные ссылки, чтобы сайт работал в подпапке GitHub Pages.
